## 用語の説明

この手順書で使う言葉の意味です。

| 用語 | 意味 |
|---|---|
| **営業セッション** | **「営業開始」** から **「営業終了」** までの一連の営業期間。1日1回の想定です |
| **営業日** | 営業セッションが紐づく日付。21時を境に切り替わります（→ [8章](#8-営業日の考え方21時境界)で詳しく説明） |
| **伝票** | お客様ごとの会計単位。1伝票にお客様の全注文がまとまります |
| **注文** | お客様がLINEから送った個別の注文。1伝票に複数の注文が入ることがあります |
| **履歴（営業日別）** | 過去の営業日の伝票一覧。**「履歴を見る」** ボタンから確認します |
| **来店履歴（お客様別）** | 特定のお客様の過去の来店記録。伝票カードの **「履歴」** リンクから確認します |

## 0. 30秒クイック運用（忙しい時はここだけ！）

> **営業の基本フロー（毎日これだけでOK）**

**1. 営業開始**
- **「営業開始」**（緑ボタン）→ **「営業を開始する」** をタップ

**2. 注文が来たら**
- **「更新」** ボタンで最新データを取得
- 繁忙時は **「自動更新(15秒)」** をON

**3. 注文を確認・提供**
- 伝票カードの **「注文 (〇件)」** で中身を確認
- 提供したら **「会計へ」** をタップ

**4. お会計**
- 会計が終わったら **「完了」** をタップ

**5. 営業終了**
- 未会計の伝票がないか確認
- **「営業終了」**（赤ボタン）→ **「営業を終了する」** をタップ

**6. ログアウト**
- 必要に応じて **「ログアウト」** をタップ

> **更新の基本方針（通信量を節約するために）**
>
> - 普段は **自動更新OFF**（デフォルト）
> - 注文を確認したい時だけ **「更新」** ボタンを手動でタップ
> - 忙しい時間帯だけ **「自動更新(15秒)」** をON
> - 落ち着いたらOFFに戻す

（※画面イメージ：伝票ボード全体）

## 1. はじめに

### Momoki でできること

Momoki は、バー・飲食店の **LINE注文管理・伝票管理** を行うシステムです。
スマホやタブレットから管理画面にアクセスし、以下の操作ができます。

- お客様からの **LINE注文の確認**
- 注文の **提供状況の管理**（提供中 → 会計 → 会計済み）
- **営業セッションの開始と終了**
- **履歴（営業日別）** の確認
- **来店履歴（お客様別）** の確認
- 注文データの **手動更新・自動更新**

### この手順書の使い方

- 各章は操作の流れに沿って並んでいます
- 太字（**太字**）は画面に表示される実際のボタン名やラベルです
- 急いでいる時は「[0. 30秒クイック運用](#0-30秒クイック運用忙しい時はここだけ)」だけ見ればOKです
- 困った時は「[10. トラブルシューティング](#10-トラブルシューティングfaq)」をご覧ください

## 2. 管理画面へのログイン方法

### ログイン手順

1. スマホのブラウザで Momoki のトップページを開きます
2. 画面下部の **「店舗スタッフの方はこちら」** をタップします
3. 管理画面のログインページが表示されます
4. **「LINEでログイン」** ボタンをタップします
5. LINEの認証画面が表示されるので、許可します
6. ログインが完了すると、**伝票ボード**（メイン画面）が表示されます

（※画面イメージ：ログイン画面）

### 初回ログイン時（管理者登録）

- 初めてログインする場合、**「管理者セットアップへ」** というボタンが表示されることがあります
- タップすると **「管理者登録」** 画面に移動します
- 店舗オーナーから受け取った **招待コード** を入力し、**「登録」** をタップしてください
- 登録が完了すると管理画面を利用できるようになります

### ログインできない時

- LINEアプリが最新版であることを確認してください
- LINEにログインした状態でブラウザを開いてください
- 招待コードが正しいか確認してください（間違っていると **「招待コードが正しくありません」** と表示されます）
- 長時間操作しなかった場合、セッションが切れることがあります → **「再ログイン」** をタップしてください

## 3. 営業開始・営業終了

### 営業開始

営業を開始すると、その時点からの注文が **営業セッション** に紐づいて記録されます。

1. 管理画面（伝票ボード）を開きます
2. 画面上部に **「営業未開始」** と表示されていることを確認します
3. **「営業開始」** ボタン（緑色）をタップします
4. 確認画面：**「営業を開始しますか?」**
5. **「営業を開始する」** をタップします
6. 画面上部が **「営業中」** に変わり、営業日と開始時刻が表示されます

（※画面イメージ：営業開始前→営業中の画面遷移）

### 営業開始後にできること

- お客様からの注文の確認
- 注文ステータスの変更（提供中 → 会計 → 会計済み）
- 手動更新・自動更新による最新データの取得

### 営業終了

1. 画面上部の **「営業終了」** ボタン（赤色）をタップします
2. 確認画面：**「営業を終了しますか?」**
3. **「営業を終了する」** をタップします

### 営業終了時の注意点

- 終了前に **未会計の伝票がないか** 確認してください
- 営業を終了しても伝票データは消えません（履歴として残ります）
- 営業終了後の注文は、次回の営業開始後の営業セッションに紐づきます

## 4. 伝票ボードの見方

伝票ボードは管理画面のメイン画面です。お客様の注文状況を一覧で確認できます。

### 画面構成（上から順に）

**1. ヘッダー（最上部）**
- ログアウトボタンがあります

**2. 営業状態の表示**
- **「営業中」**：営業日と開始時刻が表示されます（例：**「営業日: 2026-02-09 / 開始: 21:05」**）
- **「営業未開始」**：まだ営業を開始していない状態です
- **「履歴表示」**：過去の営業日を閲覧中です（操作はできません）

**3. 更新エリア**
- **「更新」** ボタン：最新の注文データを手動で取得
- **「自動更新(15秒)」** チェックボックス：15秒ごとに自動取得
- **「最終更新 〇〇:〇〇」**：最後にデータを取得した時刻

**4. 日付ナビゲーション**
- **「前日」** **「本日」** **「翌日」** ボタンと日付選択
- 営業中は日付変更できません（営業セッションの営業日に固定されます）

**5. ステータス列ジャンプボタン**
- **「提供中 (件数)」** **「会計 (件数)」** **「会計済み (件数)」**
- タップするとその列にジャンプします

**6. 伝票カード一覧**
- ステータスごとに列で表示されます

（※画面イメージ：伝票ボード全体の構成）

### ステータスの意味

伝票は3つのステータス列に分かれて表示されます。

| ステータス | 意味 | 列の色 |
|---|---|---|
| **提供中** | お客様が着席中、または注文を提供している最中 | 黄色 |
| **会計** | お会計に進んだ状態 | 緑色 |
| **会計済み** | お会計が完了した状態 | 灰色 |

### 横スワイプでの移動（スマホ・タブレット）

- スマホでは **横にスクロール** して各ステータスの列を切り替えます
- 指で左右にスワイプすると、列がぴたっと切り替わります
- 画面上部のジャンプボタンをタップしても素早く移動できます
- パソコンでは3列が横並びで一度に表示されます

## 5. 注文の確認と対応

### 伝票カードの見方

各伝票は「カード」として表示されます。カードには以下の情報があります。

- **テーブル番号**（青いバッジ。設定されていない場合は **「未設定」**）
- **お客様の名前**（不明な場合は **「不明」**）
- **「NEW 〇」** バッジ：新しい注文がある場合に赤く点滅して表示されます
- **「入店 〇時間〇分」**：入店からの経過時間
- **注文数**（例：**「3件」**）と **合計金額**（例：**「¥3,500」**）

### 注文を見る

1. 伝票カードの **「注文 (〇件)」** をタップします
2. 注文の一覧が展開されます
3. 各注文のバッジ：
   - **「NEW」**（赤）：まだ確認していない新しい注文
   - **「提供済」**（緑）：提供が完了した注文
   - **「取消済」**（赤）：取り消された注文
4. 閉じるには **「閉じる」** をタップします

### 注文を提供済みにする

1. 注文を展開した状態で、注文の右にある **「提供済」** ボタンをタップします
2. 確認画面で **「提供済にする」** をタップします

### 注文を取り消す

1. 注文を展開した状態で、取り消したい注文の **「削除」** ボタンをタップします
2. 確認画面で **「取り消す」** をタップします

> **注意：** 会計・会計済みの伝票では注文の取り消しはできません。取り消す場合は先に **「提供中に戻す」** 操作が必要です。

### 伝票のステータスを進める

注文への対応が終わったら、伝票のステータスを進めます。

- **提供中 → 会計**：伝票カード下部の **「会計へ」** ボタンをタップ
- **会計 → 会計済み**：伝票カード下部の **「完了」** ボタンをタップ

### ステータスを戻す（間違えた時）

- **会計 → 提供中に戻す**：**「提供中に戻す」** ボタンをタップ
- **会計済み → 提供中に戻す**：**「会計を取り消す」** ボタンをタップ
  - 確認画面で **「会計を取り消す」** をタップ

（※画面イメージ：伝票カードとステータスボタン）

## 6. 更新操作について

### 「更新」ボタンの使い方

- 画面上の **「更新」** ボタンをタップすると、最新の注文データをすぐに取得できます
- 更新後、**「最終更新 〇〇:〇〇」** の時刻が変わります

### 自動更新（15秒）

- **「自動更新(15秒)」** にチェックを入れると、15秒ごとに自動でデータが更新されます
- チェックを外すと停止します
- 設定はブラウザに保存されるため、次回アクセス時も同じ設定が維持されます

### 推奨する更新設定

> **基本方針：普段は自動更新OFF（デフォルト）**
>
> 通信量を抑えるため、自動更新はデフォルトでOFFになっています。
> 必要な時だけ手動で更新し、忙しい時間帯だけ自動更新を使ってください。

| タイミング | 設定 | 操作 |
|---|---|---|
| **普段（デフォルト）** | 自動更新 **OFF** | 注文を確認したい時に **「更新」** ボタンを手動タップ |
| **忙しい時間帯** | 自動更新 **ON** | **「自動更新(15秒)」** にチェックを入れる |
| **繁忙ピークが過ぎたら** | 自動更新 **OFF** に戻す | チェックを外す |
| **履歴表示中** | 更新は不要 | 過去のデータは変わらないため、自動更新は自動でOFFになります |

### 注意事項

- ブラウザのタブが非表示（別のアプリを開いている等）の場合、自動更新は一時停止します
- セッションが切れている場合は自動更新が停止します → **「再ログイン」** をタップしてください

## 7. 履歴の確認（営業日別・お客様別）

### 履歴（営業日別）を見る

過去の営業日の伝票をまとめて確認できます。

1. 伝票ボード画面で **「履歴を見る」** ボタンをタップします
2. 画面が **「履歴表示」** モードに切り替わります
3. **「前日」** **「翌日」** ボタン、または日付選択で営業日を切り替えます
4. 過去の伝票が表示されます（**閲覧のみ。ステータス変更等の操作はできません**）
5. **「本日に戻る」** ボタンをタップすると、現在の営業に戻ります

> 履歴表示中は **更新する必要はありません**。過去のデータは変わらないため、自動更新も自動でOFFになります。

### 来店履歴（お客様別）を見る

特定のお客様の過去の来店記録を確認できます。

1. 伝票カードの右上にある **「履歴」** リンクをタップします
2. そのお客様の過去の来店一覧が表示されます
3. **「← ボードへ戻る」** をタップすると伝票ボードに戻ります

> **「履歴（営業日別）」と「来店履歴（お客様別）」の違い：**
> - **履歴を見る** → その営業日の **全員の伝票** を一覧で見る
> - **履歴リンク** → **特定のお客様** の過去の来店を見る

（※画面イメージ：履歴表示モード / 来店履歴画面）

## 8. 営業日の考え方（21時境界）

### 基本ルール

Momoki では、営業日は **夜21時（午後9時）を境** に切り替わります。
深夜営業の場合、カレンダー上の日付と営業日がずれるので注意してください。

### 具体例

```
【例1】通常の夜営業
  2月9日（日） 22:00 に「営業開始」を押した場合
  ────────────────────────────────
  営業日 → 2月9日
  ├ 2/9 22:00 営業開始
  ├ 2/9 23:30 注文 → 「2月9日」の営業分
  ├ 2/10 01:00 注文 → 「2月9日」の営業分（日付は10日だが営業日は9日）
  └ 2/10 03:00 営業終了

  → 翌日確認する時は、日付を「2月9日」に合わせてください


【例2】21時前に営業開始した場合
  2月9日（日） 20:30 に「営業開始」を押した場合
  ────────────────────────────────
  営業日 → 2月9日
  ├ 2/9 20:30 営業開始
  ├ 2/9 20:45 注文 → 「2月9日」の営業分
  ├ 2/10 02:00 注文 → 「2月9日」の営業分
  └ 2/10 03:30 営業終了

  → 営業開始した日付が営業日になります


【例3】翌朝にログインして確認する場合
  2月10日（月）10:00 に管理画面を開いた場合
  ────────────────────────────────
  前日の営業は終了済み（2月9日の営業セッション）
  → 画面には「営業未開始」と表示される
  → 「履歴を見る」→ 日付を「2月9日」にすれば前日の伝票が確認できる
```

### ポイント

- **営業日 = 営業開始ボタンを押した日** と覚えてください
- 深夜の注文も、営業開始した日の営業分として記録されます
- 翌朝に確認する場合は **「履歴を見る」** から前日の営業日を選んでください
- カレンダーの日付と違っていても不具合ではありません

## 9. ログアウト

### ログアウト手順

1. 画面右上の **「ログアウト」** ボタンをタップします
2. 確認画面：**「ログアウトしますか?」**
3. **「ログアウト」** をタップするとログアウトが完了します
4. ログアウトしない場合は **「キャンセル」** をタップしてください

### 補足

- 誤操作を防ぐため、確認画面が表示されます
- 営業中にログアウトしても **営業セッションは維持されます**（営業が自動終了することはありません）
- 再度利用する場合は、LINEログインが必要です

## 10. トラブルシューティング（FAQ）

問題が起きた時は、以下から症状に近いものを探してください。

---

### 症状：注文が表示されない / 新しい注文が出てこない

**考えられる原因と対処：**

1. **データが古い**
   - **「更新」** ボタンをタップして最新データを取得してください
2. **営業が開始されていない**
   - 画面上部に **「営業未開始」** と表示されていませんか？ → **「営業開始」** をタップしてください
3. **セッションが切れている**
   - 画面上部に **「セッション切れ」** と表示されていませんか？ → **「再ログイン」** をタップしてください
4. **日付が違う**
   - 営業日が正しいか確認してください（→ [8章](#8-営業日の考え方21時境界)）

---

### 症状：「更新」を押しても反映されない

**考えられる原因と対処：**

1. **インターネット接続が切れている**
   - Wi-Fiやモバイル通信の接続を確認してください
2. **ブラウザの問題**
   - ブラウザを再読み込み（リロード）してみてください
3. **セッション切れ**
   - 一度ログアウトして、再度ログインしてください

---

### 症状：日付が違うように見える / 昨日の注文がない

**考えられる原因と対処：**

1. **営業日の仕組みによるもの（正常）**
   - Momoki の営業日は21時境界です。深夜の注文は前日の営業日に紐づきます
   - 例：2月10日の深夜1時の注文 → 営業日「2月9日」に記録されています
   - 詳しくは [8章](#8-営業日の考え方21時境界) をご覧ください
2. **確認方法**
   - **「履歴を見る」** → 日付を前日に変更 → 前日の伝票が表示されます

---

### 症状：自動更新が止まる / 動いていない

**考えられる原因と対処：**

1. **別のアプリを開いている**
   - ブラウザのタブが非表示の間は自動更新が一時停止します → 画面に戻れば再開します
2. **セッション切れ**
   - **「セッション切れ」** と表示されている場合 → **「再ログイン」** をタップしてください
3. **履歴表示モードになっている**
   - 履歴表示中は自動更新がOFFになります → **「本日に戻る」** をタップしてください
4. **チェックが外れている**
   - **「自動更新(15秒)」** のチェックが入っているか確認してください

---

### 症状：「セッション切れ」と表示される

**考えられる原因と対処：**

1. **ログインの有効期限が切れた**
   - 長時間操作しなかった場合に表示されます
   - 画面上部の **「再ログイン」** ボタンをタップしてください
2. **別の端末でログインし直した**
   - 別の端末でログインすると、前の端末のセッションが切れることがあります

### 症状：操作を間違えた

**対処方法：**

| 間違えた操作 | 戻し方 |
|---|---|
| 会計へ進めてしまった | **「提供中に戻す」** をタップ |
| 会計済みにしてしまった | **「会計を取り消す」** をタップ（確認画面あり） |
| 注文を取り消してしまった | 取り消し済みの注文は元に戻せません。お客様に再注文いただくか、管理者にお問い合わせください |

---

### 症状：スマホで画面が見づらい

**対処方法：**

- 横スワイプで **提供中 → 会計 → 会計済み** の各列を切り替えられます
- 画面上部のジャンプボタン（**「提供中」** **「会計」** **「会計済み」**）をタップしても素早く移動できます
